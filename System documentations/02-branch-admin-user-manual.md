# Branch Admin User Manual

## Role summary

Branch Admin oversees candidate records and daily operations for a single branch, with read-only access to its staff accounts.

## Main responsibilities

- view branch users and their activity report
- review candidate records for the branch
- approve or update candidate stages
- review branch-level activities and finances
- oversee branch staff operations

## Login

1. Open the login page.
2. Enter your username and password.
3. If prompted, set a new password.

## Common tasks

### View branch candidates

1. Open Candidates.
2. Use the search box to find a candidate.
3. Select a candidate to view details.

### Update workflow stage

1. Open a candidate profile.
2. Use the stage selector to change status.
3. Save the update.

### View branch users

1. Open Branch users.
2. Review the branch's user list, roles, status, and activity report.
3. Ask Super Admin to add, edit, delete, assign roles, or reset ordinary staff accounts. Branch Admin has no staff account-management controls.

### Add a recruiter / employer

1. Open Recruiters and choose Add recruiter.
2. Enter the employer name, username and email. The account is created as a Recruiter for your branch; no other role can be assigned here.
3. Use the one-time sign-in details shown or sent by email. Existing accounts can only be edited, deleted or reset by Super Admin.
4. Select an existing recruiter/employer when submitting a new job order. Salary and qualifications are displayed with the job.

### Review documents

1. Open Passport inventory or Candidate profile.
2. Check uploads and document records.
3. Confirm document type and document status.

## Access boundaries

Branch Admins should only manage:

- their own branch
- their own branch users in read-only mode
- branch-level candidate records

## Best practice

- keep document names clear
- check due and paid fees before closing a candidate file
- confirm candidate status changes before approving work
- ask Super Admin for an audit-history review when issues require it
