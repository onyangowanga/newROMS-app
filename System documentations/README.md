This folder contains user manuals and operational documentation for the ROMS recruitment management system.

## Contents

- User manual for Super Admin

- User manual for Branch Staff and Finance
- User manual for Recruiter
- Candidate user guide
- Backup and restore guide
- Troubleshooting guide
- Glossary

## System overview

ROMS is a recruitment operations and candidate management system used to:

- register and track candidates
- assign jobs and applications
- manage workflow stages
- upload supporting documents
- record finance and commission details
- handle passports and custody records
- keep a database backup and restore process

## Access levels

- Super Admin: full system access and backup controls
- Branch Admin: branch-level management and user access
- Branch Staff: candidate and document handling within a branch
- Branch Finance: finance and payment approval tasks
- Recruiter: candidate registration and application tasks
- Candidate: personal application portal

## Core workflow

1. Candidate applies for a job or is registered by staff.
2. Candidate profile and documents are gathered.
3. Workflow stage is updated according to recruitment progress.
4. Finance and commission details are captured.
5. Passport and document inventory are managed.
6. Final deployment or completion is recorded.

## Recommended training flow

1. Start with the Admin and Branch Admin guides.
2. Train branch staff and finance on daily task flows.
3. Train recruiters on candidate registration and workflow updates.
4. Brief candidates on the public application and tracking flow.
5. Review backup and restore procedures with system owners.

## Support

For operational issues, check the Troubleshooting guide first. For security-sensitive actions such as restore, only Super Admins should handle them.
