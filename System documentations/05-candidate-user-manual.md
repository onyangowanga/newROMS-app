# Candidate User Manual

## Role summary

Candidates use ROMS to apply for jobs, upload required documents, and track their application progress.

## Login and application

1. Open the public application page.
2. Fill in your personal request details.
3. Submit the application.
4. Use the tracking link or tracking number to follow progress.

## My application portal

After login, the candidate sees their Application dashboard.

### Available actions

- view assigned application details
- upload supporting documents
- review status updates
- check candidate profile information

## Documents

1. Go to Documents.
2. Select a document type.
3. Upload the file.
4. Confirm the upload succeeded.

## Status tracking

Candidates can monitor whether their application is still under review or has moved to later stages.

## Best practice

- keep contact details updated
- upload readable and complete documents
- keep track of the application reference and tracking code
- contact the recruitment office if status appears unchanged for too long
