# Branch Staff and Branch Finance User Manual

## Role summary

Branch Staff and Branch Finance carry out daily operational tasks for candidate records, document collection, and payment handling within a branch.

## Main responsibilities

- register or update candidate information
- upload and review candidate documents
- manage document inventory
- record payments
- approve pending payment items when allowed

## Login

1. Open the ROMS login page.
2. Sign in with your username and password.
3. Reset your password if required.

## Candidate workflow

### Register candidate

1. Go to Candidates.
2. Click Register candidate.
3. Enter the candidate details.
4. Save the profile.

### Upload documents

1. Open the candidate profile.
2. Go to the Documents section.
3. Select the document type.
4. Choose a file and click Upload.

### Update stage

1. Open the candidate profile.
2. Select the correct stage from the workflow dropdown.
3. Save the update.

## Finance tasks

### Record payment

1. Open Finance.
2. Click Record payment.
3. Enter applicant information, payment type, and amount.
4. Save and confirm the entry.

### Approve pending transactions

1. Open Finance.
2. Identify the pending transaction.
3. Click Approve if your role allows it.

## Passport and document inventory

1. Open Passport inventory.
2. Receive or update passport status records.
3. Confirm where each passport is stored.

## Best practices

- upload the correct document type
- verify candidate names before saving
- do not skip workflow updates
- keep accurate payment records
- if unsure, ask the Branch Admin or Super Admin
