# Troubleshooting Guide

## Common login issues

### Password reset required

If a user is prompted to set a new password, they should use the one-time password and set a new secure password.

### Forgotten password

- Super Admin or Branch Admin can reset the password from the user management screen.
- Ask the user to log in again and change the password after successful access.

## Document upload issues

### File is not uploading

- verify file size is acceptable
- confirm the file format is supported
- check internet connection
- refresh the page and retry

### File does not open

- check file type and content
- confirm the document was uploaded successfully
- review the document in the candidate profile

## Finance issues

### Payment not appearing

- check whether the transaction was saved correctly
- verify the candidate and payment type are correct
- refresh the Finance page

## Performance issues

- refresh the browser
- confirm the API service is running
- ensure the internet connection is stable
- log in again if the session appears stale

## Restore issues

- verify the selected snapshot is complete
- confirm the admin typed RESTORE ROMS exactly
- make sure no one is performing critical operations during restore
- review the system logs if the restore fails

## Contact and escalation

For critical issues:

- escalate to Super Admin
- check the Audit log
- review backup status and restore logs
- confirm recent system changes before recovery
